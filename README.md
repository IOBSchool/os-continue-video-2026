# 8月既存生販売（梅・竹・松）お申し込みページ

設計正本: SecondBrain `05_プロジェクト/IOB/2026-08-08_8月既存生販売_神田式設計.md`

## デプロイ手順（なつこさん／佳代子さん用）

1. Googleスプレッドシートを新規作成する（例：「8月既存生販売_申込管理」）
2. そのシートで「拡張機能 → Apps Script」を開き、`gas_code.gs` の中身を全部貼り付ける
3. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
4. 発行された「ウェブアプリURL」をコピーする
5. `index.html` 内の `const GAS_URL = "PASTE_GAS_WEBAPP_URL_HERE";` を書き換える
6. Stripe/PayPalの決済リンクが用意できたら、`gas_code.gs` の `CONFIG.STRIPE_LINK` / `CONFIG.PAYPAL_LINK` に貼り付けて再デプロイする
7. GitHub Pagesで公開する場合は、このフォルダの中身をリポジトリにpushし、Pagesを有効化する

## 申込管理シートに入る列

申込日時 / お名前 / メールアドレス / プラン / 希望決済方法 / お支払い回数 / モニター表記希望 / ご質問・連絡事項 / 通知結果 / 返信結果
